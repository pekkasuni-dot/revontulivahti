# Luovutus 2026-10-30 (tilannekatsaus)

Kirjoitettu session lopussa luovutusta varten. Vain koodista tai keskustelusta varmistettuja asioita;
epävarmat kohdat on merkitty **(EPÄVARMA)**. Yksityiskohtainen tekninen dokumentaatio on CLAUDE.md:ssä
(ajantasainen) ja MUISTIO-*.md-tiedostoissa. Mainin kärki: PR #160, sovellus v1.302.

## 1. Valmiit ja toimivat ominaisuudet

Sovellus (index.html + aurora-core.js + i18n.js + features.js, Capacitor-kuori iOS/Android):
- Kartta (MapLibre 3.6.2 omasta `lib/`-kansiosta): Yleiskartta (OpenFreeMap) ja Satelliittikartta (Esri),
  rantaviiva/rajat/tiet/nimet, maastovarjostus, tarkkuustasot, tiekartta lähizoomilla. Kartta ei käänny eikä kallistu.
- Pilvet: ECMWF, ICON-EU, HARMONIE ja IL (editoitu) -mallit, laiska askellataus, PNG-pakatut hilat, kerrokset
  (ala/keski/ylä), sumu (HARMONIE, ICON-EU), WebGL-pilvitaso bikubisella interpoloinnilla, lippu samalla kaavalla.
- Satelliittitaso (MTG FCI IR 10,5 µm, EUMETView, CC BY 4.0): tuorein 10 min kuva, satelliittitila
  (aikajana/malli piiloon, kuvan aika aikajanan paikalla), kuva haetaan Cloudflare Worker + R2:sta
  (`SAT_API`, Worker julkaistu ja todennettu 30.10.: latest.json vastasi, kuva ~25 min vanha).
- Tuuli: WebGL-hiukkasanimaatio, 4 korkeutta, seuraa valittua pilvimallia.
- Revontulet: NOAA OVATION -kenttä Mercator-ruudukkona, Kp nyt (reaaliaikainen), avaruussää (Bz, Bt, nopeus,
  tiheys, teho) + historiakaaviot, Tänä yönä -kaavio (V2), 7 vrk (ECMWF 7 vrk -ruudut + Kp 27 vrk).
- Infoikkuna (Nyt / Tänä yönä / 7 vrk), alapalkki, selitykset, "Ei dataa" -merkintä yhtenäisesti.
- Kamerat: YouTube-live- ja videokamerat, still-kamerat, tuoreus- ja lähetystila palvelimelta (camera-status.yml).
- Omat paikat (localStorage / Capacitor Preferences), reittiohjeet (Apple/Google/Waze/geo:).
- Tasovalikko ja infoikkuna kelluvina lasi-alaikkunina (avautuvat täyteen korkeuteen, veto puolikkaaseen/kiinni),
  yksi kulmasäde 22 px kaikille ikkunoille, ruksi kulman kanssa samankeskinen (myös ☰/✕). Pikapalkki ☰ / Pilvet /
  Kamerat / Omat paikat / Oma sijainti. Logo ei ole nappi.
- Kielet fi/en/zh-Hans/es/fr (`node scripts/check-i18n.mjs` tarkistaa avaimet), yksiköt 24 h/12 h, km/mi.
- Pro-rajaus `features.js` (rekisteri + testikytkin asetuksissa testikäännöksessä), maksut EIVÄT käytössä
  (`PAYWALL_ENABLED = false`, kaikki auki).
- Haptiikka (vain sovellus), suojakaista alareunassa, Ei yhteyttä -tila kuten Windy.

Palvelinpuoli / julkaisu:
- Data GitHub Actionsilla gh-pages-haaraan (orphan-commit, concurrency-ryhmä `gh-pages-publish`), julkaisu vain
  mainista; haaran esikatselu `esikatselu/<haara>/`.
- Pääajastin Cloudflare Worker `auroraawesome-ajastin` (cron */5), GitHubin cronit varalla + vahti-job.
- Satelliitti-Worker `auroraawesome-satelliitti` (cron */5, R2 `auroraawesome-sat`), julkaisu

- Käännökset: `ios-testflight.yml` (TestFlight, vain mainista; v1.302 käynnistetty 30.10. klo 19.00 UTC, tulos ei
  tarkistettu tässä sessiossa) ja `android-aab.yml` (artefakti).
- Versioautomaatio: `.githooks/pre-commit` nostaa APP_VERSION/sw.js CACHE (asenna `git config core.hooksPath .githooks`).

## 3. Tunnetut bugit ja rajoitukset

- Claude-ympäristöstä ei pääse ulkoisiin rajapintoihin (NOAA, ECMWF, DWD, FMI, EUMETView, YouTube, workers.dev):
  todennus vain GitHub Actionsin lokeista tai puhelimella. Kuvakaappaukset ovat synteettisellä datalla.
- EUMETView julkaisee kuvan ~25-40 min kuvausajan jälkeen -> "x min sitten" on normaalisti 25-45 min.
- Sat-kuva on yksi EPSG:3857-kuva alueelta -2…42 E, 54…72,5 N; ulkopuoli viivoitettu. Lapissa kuva on vino.
- GitHub Pagesin julkaisu jää joskus käynnistymättä (korjaus: aja `camera-status.yml` käsin). GitHubin oma
  `schedule` on epäluotettava -> Cloudflare-ajastin.
- Headless-Chromium ei zoomaa sivua -> sivun zoomauksen esto todennetaan vain puhelimella.
- iOS Safari voi kohista canvas-takaisinluvussa -> pilvi-PNG puretaan itse (`decodePngGray`), satelliittikuva
  puretaan yhä canvasin kautta (`satRecolor`); pieni kohina ei näy visuaalisesti **(EPÄVARMA: ei testattu iPhonella)**.
- YouTube `watch?v=` vastaa Actionsista 429 -> "isLiveNow"-tietoa ei saa; /streams-sivu toimii.
- Still-kameroista vain `lupa` "public domain"/"myönnetty" saa mennä kauppaversioon (nyt useimmat "ei pyydetty").
- `?debug`, `?griddebug`, `?paletti` -näkymät poistettava ennen kauppajulkaisua.
- zh/es/fr-käännökset osin tarkistamatta (`// TARKISTA`, `// TARKISTAMATON`), Omat paikat zh/es/fr englanniksi.
